# Phase 2 & 3 — Proof Checks, Implementation Validation, & Change Log Summary

## 1. Resolution of All Audited Mathematical & Methodological Flaws

| Defect / Critique ID | File / Function | Exact Flaw Identified | Implemented Fix & Verification |
| :--- | :--- | :--- | :--- |
| **`BUG-M01` (Invalid hardcoded range $R=0.5/0.65$)** | `codes/src/stopping_rules.py` | Legacy code used $R=0.50$ or $R=0.65$ without online verification, invalidating Maurer–Pontil and Hoeffding bounds on $[0,1]$. | Implemented both exact worst-case $R=1.0$ bounds (`*_valid`) and **online Delorme–Poljak / Mohar–Poljak spectrally-tightened bounds** (`*_spectral_valid` using $R_{\mathrm{spec}}(G) = U_{\mathrm{spec}}(G)/W$ on $[1 - U_{\mathrm{spec}}(G)/W, 1]$). Verified in `test_02` and `test_11`. |
| **`BUG-M02` (Unadjusted $\min$ of two full-$\alpha$ bounds)** | `codes/src/stopping_rules.py`: `intersection_eb_hoeff_ucb_valid` | Legacy code took $\min(U_{\mathrm{EB}}(\alpha_k), U_{\mathrm{Hoeff}}(\alpha_k))$, allowing combined Type-I error up to $2\alpha_k$. | Splits error budget at $\alpha_k / 2$ for each bound so Boole's inequality guarantees level $1-\alpha_k$. Verified in `test_02`. |
| **`BUG-M03` ("Holm" mislabeling for Bonferroni split)** | `codes/src/stopping_rules.py`: `allocate_alpha_k` | Legacy code labeled $\alpha_k = \alpha / K_{\max}$ as Holm-Bonferroni without step-down ordering across sequential attempts. | Renamed and implemented exact `fixed_bonferroni` ($\alpha / K_{\max}$) and `harmonic_spending` ($\alpha / (k(k+1))$). Verified in `test_03`. |
| **`BUG-M04` (Student-$t$ treated as finite-sample valid)** | `codes/src/stopping_rules.py`: `student_t_ucb_heuristic` | Student-$t$ UCB under-covers on skewed bounded QAOA distributions and divides by zero on constant prefixes. | Explicitly separated as `is_non_asymptotic_guarantee=False` with zero-variance refusal ($V_n < 10^{-10} \implies U_n = 1.0$). Verified in `test_04`. |
| **`BUG-M05` & `BUG-M06` (`time_uniform_eb_cs_valid` heuristic stitching & changing `n_horizon=max(n, 50)`)** | `codes/src/stopping_rules.py`: `time_uniform_eb_cs_valid`, `certify_candidate_split_sample` | Passing `n_horizon=max(n, 50)` inside the sequential mini-batch loop recomputed historical $\lambda_1, \dots, \lambda_t$ whenever $n > 50$, violating $\mathcal{G}_{i-1}$-measurability and allowing `best_ucb` to increase with $n$. | Default `n_horizon=None` uses horizon-free predictable scaling $i\ln(i+1)$ (Waudby-Smith & Ramdas 2024, Eq. 15), and `certify_candidate_split_sample` sets `fixed_horizon = max(max_s, 50)` once prior to the `while` loop. Verified in `test_10_regression_time_uniform_prefix_invariance_and_monotonicity`. |
| **`BUG-H04` (Spectral hash used in place of exact isomorphism test)** | `codes/src/graph_library.py`: `are_graphs_isomorphic_exact` | Spectral hashes can collide on cospectral non-isomorphic graphs or miss relabeled graphs. | Implemented exact degree + 2-hop/3-hop walk-profile pruned backtracking bijection verification across $n \in \{8, 12, 14, 16\}$. Verified in `test_08`. |
| **Critique 2 (Phase 6 confirmation-shot allocation tautology)** | `codes/experiments/run_phase6_regime_map.py` | `fixed_shaydulin_fullconf` was given 450 confirmation shots vs 120–200 for search methods, confounding method comparison with confirmation budget size. | Enforced **matched $40\%$ confirmation splits** across all methods (`Evaluation_A_EndToEnd`) plus a full split-ratio optimization sweep $\rho_{\mathrm{conf}} \in \{0.25, 0.40, 0.60, 0.80\}$ (`split_ratio_optimization.csv`). |
| **Critique 3 & 5 (Conservative calibration & small scale)** | `run_phase4_experiments.py`, `run_phase5_experiments.py`, `run_phase6_regime_map.py` | $R=1.0$ bounds showed `0.000` false certifications even under broken blinding (Variants B/D), and scale was limited to $n=8, p \le 2$. | Added spectrally-tightened bounds (`R_spec = U_spec/W`), peaked near-optimal QAOA regime (where Variants B/D reach `19.25%–21.00%` false certifications even under valid anytime CS), deliberately tight bound `eb_under_range_r05_invalid`, and scaled statevector experiments to **$n \in \{8, 12, 14, 16\}$ and $p \in \{1, 2, 3, 4\}$**. Verified in `test_11` and `test_12`. |
| **Critique 6 & 8 (Constructed Exp 4A & Wurtz–Love citation conflation)** | `run_phase4_experiments.py`, `qaoa_core.py`, `warmstart_transfer.py`, `docs/literature_review_and_citations.md` | Exp 4A swept synthetic $(M, K)$ rather than running actual optimizers; Wurtz & Love (PRA 103:042612) was conflated with Wurtz & Lykov (PRA 104:052419). | Added Part 4A-1 (`exp4a_actual_optimizer_insample_audit.csv`) executing the actual optimizers under global nulls (`70%–77.5%` in-sample false certification vs `0%` split-sample), and verified all primary-source citations and DOIs. |
